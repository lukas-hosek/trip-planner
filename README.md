# TripMap

An interactive, offline-capable map for trip plans: numbered pins on a hiking map, a list of places, and a detail card for each place with a photo, tips and links. It installs as an app on your phone and works without a signal on the trail. The interface is in Czech, English or German: it follows the browser's language and can be changed in the app settings. Try it at **https://lukas-hosek.github.io/trip-planner/**. The first visit opens a demo plan of a week in Spain.

Plans are made with Claude or ChatGPT. Download the [trip-map skill](https://lukas-hosek.github.io/trip-planner/trip-map-skill.zip) ([source](skills/trip-map/)) and upload it in Claude under **Settings → Capabilities → Skills**, with code execution turned on, or add it to your skills in ChatGPT. Plan a trip in a chat, and when it's settled, ask for an export ("Export the plan to the map"). The assistant replies with the plan's JSON file and a small page whose button opens the plan in TripMap and saves it in your browser.
